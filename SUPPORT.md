# Support & Community

Thank you for using projects maintained by **AtlasInference**.

## Where to Get Help

* **Usage Questions & Ideas:** Check existing discussions or open a thread in the repository's **Discussions** tab.
* **Bug Reports:** Open an issue in the relevant repository using the bug report template, including your environment details and minimal reproduction steps.
* **Feature Requests:** Review the organization **[ROADMAP.md](https://github.com/AtlasInference/.github/blob/main/ROADMAP.md)** first, then open a feature request issue in the target repository.
