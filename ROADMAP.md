# atlasinference Roadmap

atlasinference focuses on **AI infrastructure, runtime efficiency, and applied deployment workflows**—from low-level C++ kernels to end-to-end training and retrieval pipelines.

## Active Repositories (Phase 1)
* **[optimization-kernels](https://github.com/atlasinference/optimization-kernels)** — C++ kernels and low-level utilities for quantization and inference acceleration.
* **[finetune-pipelines](https://github.com/atlasinference/finetune-pipelines)** — Practical, reproducible LLM fine-tuning pipelines and recipes in Python.
* **[rag-starter](https://github.com/atlasinference/rag-starter)** — Lightweight Python starter architecture for retrieval-augmented generation workflows.

## Planned Repositories (Phase 2)
* **`inference-bench`** — Standardized latency, throughput, and memory-footprint benchmarking harness across hardware backends.
* **`serving-runtime`** — Lightweight, low-overhead HTTP/gRPC inference server designed for quantized models.
* **`embedding-pipelines`** — High-throughput chunking, indexing, and vector-store ingestion utilities.

## Future Exploration (Phase 3)
* Speculative decoding runtimes, edge-device quantization profiles, and automated hardware-aware kernel selection.
