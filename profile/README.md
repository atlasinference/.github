# atlasinference

**Open-source infrastructure for model training, quantization, inference optimization, and scalable deployment.**

atlasinference builds practical systems tooling that bridges the gap between raw model weights and fast, reproducible production workflows.

### Core Repositories
* **[optimization-kernels](https://github.com/atlasinference/optimization-kernels)** — C++ kernels and low-level utilities for quantization and inference acceleration.
* **[finetune-pipelines](https://github.com/atlasinference/finetune-pipelines)** — Practical, reproducible LLM fine-tuning pipelines and recipes in Python.
* **[rag-starter](https://github.com/atlasinference/rag-starter)** — Lightweight Python starter architecture for retrieval-augmented generation workflows.
